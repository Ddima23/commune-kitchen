# Commune Kitchen — Quick Start

AI tools for small communal kitchens, co-living houses, B&Bs and tiny restaurants (Finland / Åland focus).

## Install (2 minutes)
1. Open DSH → **Plugins → Discover**.
2. Add this index URL:
   ```
   https://raw.githubusercontent.com/Ddima23/commune-kitchen/main/index/index.json
   ```
3. Find **Commune Kitchen** → **Install**.
4. That's it — 4 tools and the free skill are live. (Premium skills come with the paid pack.)

## What you can do

### 1. Check a delivery against a receipt
Photograph the receipt and say: *"check this receipt against my order"*. The agent reads it (local OCR), parses it, and returns a tick-off checklist: received / short / missing / not-on-order / use-first / expired.

### 2. "What can I cook?"
List what's in stock and ask. It ranks dishes by how much you already have and avoids repeating recently cooked meals.

### 3. Scale a recipe & handle allergies
*"Scale köttgryta to 15 people, 2 are gluten-free"* → it scales quantities and flags/substitutes the 14 EU allergens (with a calculator).

### 4. Build an order sheet
Give the week's menu and headcount → it returns a supplier-ready order sheet with waste buffers.

### 5. Finnish food-safety (premium)
Self-monitoring (omavalvonta), temperature logs, allergen labelling, Oiva/ÅMHM readiness.

## Languages
Product names and receipts work in 13 languages: English, Finnish, Swedish, Portuguese (BR), Spanish, German, French, Italian, Russian, Norwegian, Danish, Dutch, Polish.

## Notes
- OCR is **local** (Tesseract). First use downloads the language model (~2–15 MB).
- The free tier ships the `recipe-scaling-allergens` skill; the other four skills are in the paid pack.
